Q1. What do you know about functions?
Ans: A function is a reusable block of code used to perform a specific task.

Q2. What is layout?
Ans: Layout is the structure or arrangement of elements on a webpage.

Q3. What do you know about Flex layout?
Ans: Flex layout is a CSS technique used to arrange and align elements mainly in a row or column.

Q4. What is the need for Grid layout?
Ans: Grid layout is a CSS technique used to create two-dimensional layouts with rows and columns.

Q5. What is the use of GitHub?
Ans: GitHub is a cloud-based platform used to store, manage, and track the history of projects.
